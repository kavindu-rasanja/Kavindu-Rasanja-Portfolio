Run locally
The exact commands depend on the framework and package scripts used by this project.
1. Clone this repository:
   git clone https://github.com/kavindu-rasanja/kavindu-rasanja-portfolio.git
2. Open the project folder.
3. Follow the setup instructions for the project's actual framework. If the repository contains a package.json, check its scripts section for the available development and build commands.
Note: Do not run npm install unless the project has a package.json file.

Deployment
The live portfolio is hosted on Vercel. To deploy your own copy, import this repository into Vercel and configure the build settings to match the framework used in the project.
